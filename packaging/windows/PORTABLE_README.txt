DocSeek Windows 便携版
======================

DocSeek 是一个完全本地运行的文档正文搜索工具：像 Everything 一样快速找文件，但重点搜索 Word、Excel、PowerPoint、PDF 和文本文件里的内容。

使用方法
--------
1. 请先把整个 ZIP 解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 DocSeek.exe。
3. 点击“添加目录”，选择你希望建立索引的办公资料目录。
4. 等待已有文件逐步建立索引；已完成的内容即可搜索。

重要说明
--------
- DocSeek 不会上传文档内容，索引和搜索都在本机完成。
- DocSeek 只读取你主动添加的索引目录。
- “排除目录”“文件排除规则”只影响 DocSeek 索引，不会删除源文件。
- 索引数据库默认保存在：%USERPROFILE%\.docseek\docseek.db
- 索引数据库包含从文档提取的正文和元数据，应视为敏感数据，并依赖当前 Windows 用户权限保护。
- 暂停目录只停止更新，已有搜索结果仍会保留。
- 删除 DocSeek 索引或数据库不会删除原始文档。

文件格式
--------
便携包内已包含：
- DOCX / XLSX / PPTX / PDF / TXT 等直接解析能力；
- XLS / XLSB / ODS 等 Calamine 本地解析能力；
- 部分旧 Office / OpenDocument 格式的本地 Tika 兼容解析能力。

部分 WPS/旧版 Office 格式可在本机已安装并注册 WPS Office 时使用 WPS 自动化兼容路径。便携包包含所需 Python Windows 组件，但不会捆绑 WPS Office 本身。

便携版目录
----------
DocSeek.exe 旁边的运行库目录是程序的一部分，请不要只复制 DocSeek.exe 单独使用，也不要随意删除内部 DLL/资源文件。

Windows 安全提示
----------------
当前便携构建尚未进行商业代码签名，因此部分 Windows/企业终端安全策略可能显示“未知发布者”或阻止运行。这不影响 DocSeek 的本地工作方式，但正式大范围部署前应补充代码签名和组织内软件分发流程。

问题排查
--------
- 某个文件没有被索引：打开“索引设置 → 索引状态”查看具体原因并可一键重试。
- 某个目录暂时不想更新：在“索引设置”中取消勾选该目录即可暂停，不必删除索引。
- 搜索语法不熟悉：按 F1 打开内置搜索帮助。

项目原则
--------
DocSeek 的目标不是做一个大而全的知识库，而是做一个简单、可靠、长期驻留在办公电脑上的本地正文搜索工具。
