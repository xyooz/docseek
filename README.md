# DocSeek

DocSeek 是一个面向 Windows 办公环境的本地全文检索工具，目标是提供接近 Everything 的易用体验，同时支持按文件内容检索 Word、Excel、PDF、TXT 等常见办公文档。

## 设计目标

- 完全本地运行，不上传文件内容
- 用户自主选择索引目录
- 后台建立索引，避免阻塞界面
- 使用 SQLite FTS5 实现快速全文检索
- 支持中文办公文档检索
- 显示命中上下文与文件路径
- 双击结果调用系统默认程序打开文件
- 为后续增量索引、预览、中文分词与语义检索预留扩展空间
